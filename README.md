# Smartslot
slot book karo, aur time bachao

*Smart Resources Booking Platform* = Book anything online and save time ⏰
*How does it work? 4 Simple Steps*

*1. Login & See Available Resources*
- Student/Teacher opens the app
- Check calendar: "Is the Lab free tomorrow 2PM-4PM?"
- Photo, location, and capacity will be visible

*2. Book in 2 Clicks*
- Select slot → Write reason → Book it
- AI will check: Is there any clash? Who has priority?
- Instant Confirmation + QR Code will be received

*3. Smart Features - This is what makes it "Smart"* 
- *Auto Reminder*: WhatsApp/Email 30 min before
- *AI Suggest*: "Projector is mostly free on Tuesday at 3PM"
- *No-Show Penalty*: If you book but don't come, your priority goes down next time
- *Real-time Status*: Notify others if someone is late

*4. Admin Dashboard*
- Which resource is used the most
- Who is misusing it
- Auto-generated reports

*Hackathon Flow*
`User → Login → Search Resource → Select Time → Book → Get QR → Scan at Door → Use → Auto Release`

*Tech Used*
- *Frontend*: App/Website - simple HTML, CSS and JavaScript 
- *Backend*: Database - who booked when
- *Smart Part*: AI for suggestions + Notifications + Fraud check

*Real-life Examples*
1. *College*: Book Lab, Seminar Hall, Sports equipment
2. *Office*: Book Meeting room, Car, Laptop  
3. *City*: Book Community Hall, Ground
